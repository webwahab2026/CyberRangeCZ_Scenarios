# Gafgyt Botnet Investigation

## INFO_LEVEL
The network has experienced unusual traffic patterns and performance degradation. Your task is to investigate and identify the source of these issues.

## ACCESS_LEVEL
You have SSH access to the bot1 host with the following credentials:
- Username: cyrano
- Password: cyrano

## TRAINING_LEVEL
### Task 1: Suspicious Beacon Service Discovery
**Description:**
Investigate the bot1 host and identify any unauthorized or suspicious services that might be responsible for periodic external communication.

**Learning Objective:**
Enumerate running services and identify beaconing behavior associated with botnet activity.

**Hint:**
Check running services and systemd timers for any unusual activity.

### Task 2: C2 Communication Discovery (IP Address)
**Description:**
Determine the external host that the compromised system is communicating with.

**Learning Objective:**
Investigate network connections and identify the command-and-control server.

**Hint:**
Examine network connections and logs for any suspicious outbound traffic.

### Task 3: Flood Attack Target Identification
**Description:**
Identify the system receiving the abnormal volume of network traffic generated by the compromised host.

**Learning Objective:**
Analyze network flows to determine the victim of the flooding activity.

**Hint:**
Review network logs and connections to find the target of the flood attack.
