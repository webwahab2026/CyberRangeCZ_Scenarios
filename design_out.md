## TRAINING_LEVEL
### Task 1: Suspicious Beacon Service Discovery
**Description:**
Investigate the bot1 host and identify an unauthorized or suspicious service responsible for periodic external communication.

**Learning Objective:**
Enumerate running services and identify beaconing behavior associated with botnet activity.

**Hint:**
Check running services and systemd timers for unusual activity.

### Task 2: C2 Communication Discovery (IP Address)
**Description:**
Determine the external host communicating with the compromised system.

**Learning Objective:**
Investigate network connections and identify the command-and-control server.

**Hint:**
Examine network connections and logs for external communication patterns.

### Task 3: Flood Attack Target Identification
**Description:**
Identify the system receiving the abnormal volume of network traffic generated by the compromised host.

**Learning Objective:**
Analyze network flows to determine the victim of the flooding activity.

**Hint:**
Review network traffic logs to identify the target of the flood attack.

---

**Validation:**
The scenario will be validated based on the correct identification of the suspicious service, the command-and-control server IP address, and the flood attack target. The solution should demonstrate a thorough investigation process using available tools and logs on the bot1 host.
