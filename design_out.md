# Scenario: Linux/Remaiten Botnet Investigation

## INFO_LEVEL
The network has experienced unusual traffic patterns and performance degradation. Initial investigations suggest a potential botnet infection. Your task is to identify and analyze the compromised systems, determine the command-and-control infrastructure, and implement containment measures.

## ACCESS_LEVEL
You have SSH access to the bot1 host with the following credentials:
- Username: cyrano
- Password: cyrano

## TRAINING_LEVEL 1
**Task:** Identify and investigate an unauthorized or suspicious service responsible for periodic external communication.

**Question:** What is the name of the suspicious service that communicates with an external host?

**Hint:** Check running services and look for unusual network connections.

**Validation:** The service name must match the exact name of the beacon service running on the system.

## TRAINING_LEVEL 2
**Task:** Determine the external host communicating with the compromised system.

**Question:** What is the IP address of the command-and-control server?

**Hint:** Investigate network connections and look for unusual destinations.

**Validation:** The IP address must match the exact IP address of the command-and-control server.

## TRAINING_LEVEL 3
**Task:** Identify the system receiving the abnormal volume of network traffic generated by the compromised host.

**Question:** What is the IP address of the system being targeted by the flood attack?

**Hint:** Analyze network flows to determine the victim of the flooding activity.

**Validation:** The IP address must match the exact IP address of the victim system.
