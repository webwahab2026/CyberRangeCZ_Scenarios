# Hajime Botnet Investigation

## INFO_LEVEL
The network has experienced unusual traffic patterns and potential security incidents. Your task is to investigate and respond to these issues.

## ACCESS_LEVEL
You have SSH access to the victim machine with the following credentials:
- Hostname: victim
- Username: ubuntu
- Password: ubuntu

## TRAINING_LEVEL 1
**Task:** Investigate the victim machine for any unauthorized or suspicious services that might be responsible for periodic external communication.

**Hint:** Check running services and system logs for any unusual network activity.

**Validation:** The service name must be identified and reported.

## TRAINING_LEVEL 2
**Task:** Determine the network port used for suspicious command-and-control communication on the victim machine.

**Hint:** Analyze network connections and logs to identify unusual outbound connections.

**Validation:** The C2 port number must be identified and reported.

## TRAINING_LEVEL 3
**Task:** Identify the system receiving the abnormal volume of network traffic generated by the compromised host.

**Hint:** Examine network flows and logs to determine the target of the suspicious traffic.

**Validation:** The victim IP address must be identified and reported.
